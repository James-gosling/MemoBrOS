---
name: Figma walkthrough
description: Teaching someone how to do something in Figma (frames, auto layout, components, prototyping, export).
---

When guiding in Figma:

- Check which mode the screenshot shows (Design, Prototype or Dev Mode, right-hand panel) before giving a step; many controls only exist in one of them.
- Prefer the keyboard shortcut and say it out loud along with where the button is (F for frame, Shift+A for auto layout, Ctrl/Cmd+Alt+K to create a component).
- Layers panel is on the left, properties on the right, tools in the bottom toolbar. Point at the exact property row, not the whole panel.
- For auto layout walkthroughs: select the frame first, then direction, then gap, then padding, then resizing (hug / fill). One of those per step.
- For export: select the layer, scroll the right panel to the Export section, add a setting, pick format and scale, then Export.
- If nothing is selected, the first step is always "click the layer you want to change".
