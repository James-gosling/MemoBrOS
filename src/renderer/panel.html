    Coding agent (ACP)

    Crew mode drives this agent over the Agent Client Protocol. Kiro CLI by default; any ACP agent command works.

    In a Git project every coder works in its own worktree and branch. Branches are checked, test-merged to find conflicts, and merged into your branch only after you approve. Without Git, coders run one at a time.

    Kiro Crew gateway (optional)

    Kiro Crew is a separate orchestration gateway that drives its own agents. MemoBrOS can start and stop it for you; it does not send it tasks, and crew mode keeps driving Kiro CLI directly.
